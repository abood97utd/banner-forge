What Banner Forge does

		
Banner Forge is a free, browser-only text banner generator. Type a word, a name or a project title and it is drawn as large letters made of Unicode box-drawing characters (╔═╗ ┌─┐ ┏━┓ ╭─╮), solid blocks (█ ▓ ░) or plain ASCII (# * +-|). Nothing is uploaded; everything runs locally in your browser.

		
Where people use these banners

		
    
			
  • SQL Server, MySQL and PostgreSQL scripts: a readable header block above stored procedures, functions and migration scripts.
    • 
			
  • Windows batch files and PowerShell scripts: a start-up banner in the console (the CMD format adds chcp 65001 so box characters display correctly).
    • 
			
  • Bash, Python, Node.js and C# programs: a splash banner printed when the tool starts.
    • 
			
  • README files, code comments, GitHub issues and any place that renders monospace text.
    • 
		

		
Tips

		
    
			
  • Arabic and Persian text is supported (letters join inside words, drawn right-to-left); accented Latin letters are simplified.
    • 
			
  • Use the ASCII styles (hash, stars, ASCII lines) when the file may be opened in an editor that does not support UTF-8.
    • 
			
  • Put each word on its own line to stack banners vertically and keep them narrow.
    • 
			
  • Copy pastes the exact text; Download saves a UTF-8 .txt file.
